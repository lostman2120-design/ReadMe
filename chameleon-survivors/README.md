# 🦎 Chameleon Survivors

ヴァンパイアサバイバーズ系の、**シンプル操作 × 中毒性**を狙ったローグライト・サバイバーゲームのプロトタイプ。
「めっちゃカメレオ」「Vampire Survivors」「Ragdoll」系の良いところ＝*操作は超シンプル、でも成長ループでつい続けてしまう*を1ファイルで再現しています。

主人公は**カメレオン女子**（オレンジ×緑の髪、薄緑の肌、メイド風衣装、カメレオン尻尾）。`assets/` の公式キャラ絵を使い、**8方向（前後左右＋斜め）×アイドル/歩行2コマ**を移動方向・移動中フラグで切り替えます（画像が無い場合はコード生成のドット絵にフォールバック）。

> 装備品は現在、ステータス効果＋HUDアイコンのみ（キャラ絵に重ねる見た目は公式絵に合わせて今後対応）。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要・依存ゼロ）。

```bash
# どれか
open chameleon-survivors/index.html          # macOS
xdg-open chameleon-survivors/index.html       # Linux
# もしくはローカルサーバ
python3 -m http.server   # → http://localhost:8000/chameleon-survivors/
```

スマホでもタッチで遊べます（画面ドラッグで移動）。

## 操作

| 操作 | キー |
|------|------|
| 移動 | `WASD` / 矢印キー / 画面ドラッグ |
| 攻撃 | **自動**（最も近い敵へ舌が伸びる） |
| 強化選択 | カードをクリック／`1` `2` `3` |
| 一時停止 | `P` / `Esc`（タブを離れると自動停止） |
| 消音 | `M` |

効果音は WebAudio で生成（音声ファイル不要）。最初のクリックで有効化されます。

## ゲームの肝（中毒性の設計）

- **自動攻撃**：プレイヤーは「避ける・位置取り」だけに集中（舌は敵が射程に入った瞬間に反応）
- **群れ（スウォーム）**：時間とともに敵が増え・強くなる → 緊張感が右肩上がり（増加ペースは調整済み）
- **XP → レベルアップ → 3択強化**：ヴァンサバの核。引きとビルド構築の楽しさ
- **多彩な敵**：ハエ・蝶・蝙蝠・ハチ・カブトムシ・ゾンビ・ボス（スパイク）など、シルエットの異なる7種をドット絵で描き分け。時間経過で強い種類が増える
- **倒した敵を食べる**：撃破した敵は経験値の塊となってカメレオンの口に吸い込まれる（食べるモーション＋チョムッ音）。LPの「食べつくせ」を体現
- **9種の強化**：舌の速度/威力/射程/多段、移動速度、HP、再生、大食い（XP+）… でビルドが分岐
- **装備品（頭／胴の2スロット）**：鉄兜（防御）/羽帽（速度）/不屈のヘルム（シールド）/狙撃ゴーグル（攻撃）/戦の鎧（攻撃大）/重甲羅（防御大）/巨大化スーツ/再生コート…効果は重ねがけ、**見た目もドット絵で変化**（兜・羽・王冠・ゴーグル・鎧・甲羅・巨大化・シールドリング）
- **宝箱**：マップに🎁が出現（画面外なら端にマーカーで方向表示）。開けると**約50%で装備品3択／約50%で体力回復**
- **ランダムバイオーム**：開始ごとに「森の平野／岩地／サイバー基地」を抽選、背景プロップを手続き生成
- **ドット絵＋陰影**：プレイヤー・敵をピクセルスプライト化（接地影つき、左右フリップ）
- **サウンド & BGM**：効果音＋WebAudioで生成するチップチューンBGM（ファイル不要、`M`で消音）
- **自己ベスト記録**（localStorage）：「あと1回」を誘発

## Steam で売るには

このHTML5プロトタイプは、そのままSteam配信用にラップできます。王道ルート：

1. **デスクトップ化**：[Tauri](https://tauri.app/)（軽量・推奨）か Electron でラップ → Win/Mac/Linux 実行ファイル化
2. **Steamworks 連携**：[Steamworks SDK](https://partner.steamgames.com/) で
   実績・クラウドセーブ・Steamオーバーレイ・ストレージを追加
   （`steamworks.js` 等のNodeバインディングを使うとTauri/Electronから呼べる）
3. **ストア登録**：Steam Direct（$100/作品）でアプリ登録 → ストアページ・ビルドアップロード・審査
4. **規模が必要になったら**：本格的にやるなら [Godot](https://godotengine.org/)（GDScriptへ移植、Steam実績プラグイン豊富・無料）への移植も有力

> 注: 本リポジトリはプロトタイプ（ゲームデザイン検証用）です。実際の販売には、上記のラップ・ストア審査・規約対応が必要です。
