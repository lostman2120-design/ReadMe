# 💸 GIGA家計簿 ULTRA

無駄にエフェクトが派手な家計簿Webアプリ。

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要・依存なしの単一HTMLファイルです。

```
open budget-app/index.html
```

データはブラウザの localStorage にのみ保存されます(サーバー送信なし)。

## 機能

- 収入・支出の記録(カテゴリ・メモ・日付つき)、削除
- 残高 / 今月の収入 / 今月の支出のサマリー(カウントアップアニメ付き)
- 今月のカテゴリ別支出ドーナツチャート(凡例・直接ラベル・ホバーツールチップ)
- 直近7日間の支出バーチャート
- 残高ランク(🍞 パンの耳 〜 🌌 宇宙富豪)

## 無駄に派手なエフェクト一覧

- 🌌 流れる星空パーティクル背景 + オーロラブロブ
- 🌈 レインボー発光タイトル / 回転ネオンボーダー
- 🎉 取引追加で紙吹雪、収入で🪙コインの雨 + ファンファーレ
- 💸 支出で札束が飛び、¥10,000以上で画面シェイク + 🔥
- ✨ マウスカーソルのキラキラ軌跡
- 🎮 カードの3Dチルト、WebAudio合成の効果音(OFFにもできます)

`prefers-reduced-motion` 設定時はアニメーションを抑制します。
